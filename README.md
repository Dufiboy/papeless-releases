# Papeless

A calm, local-first notes app for macOS. Every note is a plain Markdown file in a folder you choose — nothing lives in a cloud, and any other app can open your notes.

- Write with bullets, to-dos with deadlines, tables and flowcharts
- See any note as a mind map, or the note and its map side by side
- Link notes with `[[links]]`; a note shows which notes link to it
- Catch a thought from any app with ⌃⌥Space

"Papeles" means papers in Tagalog — Papeless keeps them tidy.

## Download

Get the **Papeless-1.0.x.dmg** file from the [latest release](https://github.com/Dufiboy/papeless-releases/releases/latest).

Requires a Mac with Apple silicon (M1 or later).

## Opening it the first time

Papeless isn't signed with an Apple developer certificate yet, so macOS asks before opening it the first time:

1. Open the DMG and drag Papeless to Applications.
2. In Applications, right-click Papeless › **Open**, then click **Open** again.

After that it opens normally. (On newer macOS versions: if there's no Open button, go to System Settings › Privacy & Security and click **Open Anyway** next to Papeless.)
